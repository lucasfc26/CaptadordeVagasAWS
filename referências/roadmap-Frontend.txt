Crie o frontend completo de uma aplicação web SaaS para monitoramento automático de vagas de emprego da Amazon Warehouse Jobs.

O projeto deve ter uma aparência moderna, profissional e premium, seguindo um padrão semelhante aos meus projetos atuais de software, utilizando:

- TypeScript
- React
- Vite
- TailwindCSS
- Componentização
- Lucide Icons
- TanStack Query para comunicação com API
- React Router
- Forms com validação
- Arquitetura organizada e escalável
- Design responsivo
- Dark mode como aparência principal
- Código limpo e fortemente tipado

A aplicação deve estar preparada para consumir uma API REST desenvolvida separadamente em NestJS + Prisma ORM + PostgreSQL.

IMPORTANTE:
Não criar um frontend genérico de administração.
O produto deve parecer um SaaS real, moderno e pronto para produção.

==================================================
1. OBJETIVO DO SISTEMA
==================================================

O sistema monitora páginas de vagas da Amazon Warehouse Jobs e identifica quando uma nova vaga aparece.

O usuário poderá configurar buscas por:

- localização
- raio/distância
- palavras-chave
- tipos de vaga
- cargos
- frequência de monitoramento
- canais de notificação

Exemplo de busca:

"Warehouse Associate / Fulfillment Center / Delivery Station"

Localização:

Richmond, CA

Cidades próximas:

- Richmond
- San Pablo
- Pinole
- Hercules
- El Cerrito

O principal objetivo da interface é permitir que o usuário descubra rapidamente:

1. quais vagas estão disponíveis agora;
2. quais vagas são novas;
3. quando uma vaga foi encontrada;
4. quais vagas já foram visualizadas;
5. quais buscas estão sendo monitoradas;
6. se o monitoramento está funcionando;
7. quais notificações foram enviadas.

19. ATUALIZAÇÃO AUTOMÁTICA
==================================================

Como o sistema monitora vagas automaticamente, o frontend deve estar preparado para receber atualizações.

No dashboard:

- atualizar automaticamente
- mostrar "Última verificação"
- mostrar "Próxima verificação"
- destacar novas vagas

A frequência real do scraping/monitoramento pertence ao backend.

O frontend apenas consulta o estado atual fornecido pela API.

Se futuramente for implementado WebSocket/SSE, deixar a arquitetura preparada para isso.
